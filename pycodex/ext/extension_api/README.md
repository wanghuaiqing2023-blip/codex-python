# pycodex.ext.extension_api

Rust crate: `codex-extension-api`

Rust anchor: `codex/codex-rs/ext/extension-api`

This package mirrors the public crate interface exported from
`ext/extension-api/src/lib.rs`. Its subpackages preserve the Rust module
coordinates for capabilities and contributors; `registry` and `state` own
extension registration and scoped extension data.
